Tema base de bloques para los sitios generados por IAprop.tech (inmobiliaria, clínica, restaurante, servicios, tienda, oficios, educación, turismo, genérico).

== Atribución ==
Derivado del tema Ollie (https://olliewp.com), (C) Mike McAlister, GPL v3. Se conservan su theme.json, estilos de bloque y la mayoría de sus patrones genéricos; se eliminaron los patrones de WooCommerce, precios, menús y blog avanzado, y se agregaron patrones por arquetipo en español.

== Variaciones ==
Las variaciones de color (styles/colors) y tipografía (styles/typography) se generan por sitio desde el backend (backend/src/entrevista/tema.js) a partir de la base web_builder (diseno_estilos + arquetipos.diseno). Las de Ollie se conservan como ejemplo.
